Privacy Policy for Tax Web Assistant

Effective Date: 2026-06-01

Last Updated: August 2026

Tax Web Assistant (hereinafter referred to as "the Extension") is a browser extension tailored exclusively for corporate finance professionals. Its core function is to provide auxiliary automation tools on official electronic tax bureau websites, reducing repetitive manual operations and improving tax processing efficiency.

1. Data Collection and Purpose Specification

We prioritize your data security. To deliver the extension's core functionality, we collect and process only the following necessary data:

  • Authentication Information (Session Cookies): Temporary session cookies from the official electronic tax bureau domain (*.chinatax.gov.cn), used only to maintain your logged-in session status on the tax bureau website.

No other data is collected: We do not access your browsing history, personal information, financial data, or any content on webpages outside the official tax bureau domain.

2. Data Transmission and Destination

★ Clear Disclosure of Data Transfer: To implement the extension's cloud synchronization and login authentication features, the extension will temporarily send the collected session cookies to the following designated secure interface address:

Login API URL: https://etax.chechebj.com/prod-api/cc/etax/plugin/login

This transfer is executed only when you actively initiate the login/sync function, and is restricted to the secure, officially authorized interface above. No data will be sent to any other server or domain.

3. Use of Collected Data

The collected data is used exclusively for the following declared purposes:

  • Verify your legitimate login identity on the electronic tax bureau website;
  • Maintain your continuous login session during use, avoiding repeated authentication;
  • Implement the extension's core functions: seamless data connection and auxiliary processing on tax bureau web pages.

Your data will never be used for any unrelated purposes, including but not limited to advertising, user profiling, or commercial analysis.

4. Data Storage and Retention

We adopt a strict "temporary processing" principle:

  • All collected session cookies are stored only in your browser's volatile memory and are automatically cleared when you close the browser tab or exit the browser.
  • The data sent to the above login API address will be processed in real time by the server and immediately deleted after the authentication session ends. No persistent user data will be retained on the server.
  • We do not use any remote cloud storage to save your personal data or sensitive information.

5. Data Sharing and Disclosure

We solemnly promise:

  • We will not share, sell, or rent your data to any third-party organizations, advertisers, or marketing groups;
  • We will not disclose your data to any third party unless required by mandatory laws or court orders;
  • The only data transfer is to the designated login API address specified in Section 2, which is solely for the purpose of providing the extension's core functions.

6. Required Permissions Justification

The extension applies for the following browser permissions only for the purposes described in this policy:

  • cookies: Access session cookies of the official electronic tax bureau website to maintain your login status;
  • host permissions: Allow access only to the official tax bureau domain (*.chinatax.gov.cn) and the designated login API address above, to implement data parsing and secure transmission;
  • activeTab: Temporarily access the current tax bureau tab content only when you activate the extension;
  • scripting: Run necessary local scripts to analyze tax webpage content and implement auxiliary functions;
  • downloads: Save processed tax files to your local device for archiving.

7. User Rights and Control

You have full control over your data and the extension:

  • You can disable or uninstall the extension at any time to stop all data processing and transmission immediately;
  • You can revoke the extension's browser permissions at any time through the browser's extension settings;
  • You can contact us at any time to request access to, correction of, or deletion of your data.

8. Remote Code Statement

All executable logic of this extension is embedded in the installation package. It will not load or execute any remote malicious code, third-party scripts, or dynamic code from the internet. The only network request is the secure data transfer to the designated login API address specified in Section 2.

9. Revision of This Privacy Policy

We may update this policy occasionally to reflect changes in our practices or legal requirements. The updated version will be posted on this page with a revised "last updated" date. Please review it periodically for any changes.
