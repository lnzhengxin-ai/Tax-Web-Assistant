Privacy Policy for Tax Web Assistant

Effective Date: 2026-06-01

Tax Web Assistant (the "Extension") is a browser extension designed specifically for corporate finance professionals. It automatically identifies tax-related information directly within electronic tax bureau websites, minimizing manual data entry and boosting overall tax processing efficiency.

1. Data Collection

This Extension does NOT collect, store, transmit, or share any personal information, browsing history, or identifiable user data. All data processing happens locally in the user's browser and is never sent to external servers. The Extension only accesses data displayed on tax bureau websites to provide its core functionality, and this data is not retained after the user closes the tab or the browser.

2. Permissions Usage

  • cookies: To maintain login status on tax and invoice platforms, ensuring normal access to webpage content.
  • activeTab: To obtain temporary access to the current tab only when the user activates the Extension, for processing tax and invoice content.
  • scripting: To run necessary scripts to parse tax and invoice data on web pages and implement auxiliary functions.
  • tabs: To retrieve basic tab information to intelligently identify tax and invoice pages.
  • downloads: To save exported tax and invoice data files to local devices for archiving.
  • host permissions: To access official electronic tax bureau and invoice-related websites only, to extract structured data and enable seamless data connection.

3. Data Processing and Storage

The Extension processes all data locally on the user's device within the browser environment. No data is transmitted to external servers. All temporary data used during processing is kept only in the browser's memory and is automatically cleared when the Extension is closed or the browser is exited.

No persistent user data is stored on the device unless explicitly saved by the user via the download function, in which case the data is saved locally as a file chosen by the user and never shared or uploaded.

4. Data Sharing

No user data is shared with any third party. The Extension does not transmit any data to external servers, advertisers, analytics providers, or other third parties. All operations are isolated to the user's local browser environment.

5. Remote Code

This Extension only uses locally built, embedded code. It does not load or execute any external remote code, third-party scripts, or dynamic code from the internet.

6. User Rights and Control

Since the Extension does not collect or store any personal data, there is no user data to access, modify, or delete. Users retain full control over the Extension at all times:

  • Users may disable or uninstall the Extension at any time to stop all functionality immediately.
  • Users may revoke permissions granted to the Extension via the browser's extension settings at any time.

7. Changes to This Privacy Policy

We may update this Privacy Policy from time to time. Any changes will be posted on this page with a revised "Effective Date." Users are encouraged to review this policy periodically.
