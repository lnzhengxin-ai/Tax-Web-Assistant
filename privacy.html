Privacy Policy for Tax Web Assistant

Effective Date: 2026‑06‑01

Tax Web Assistant (hereinafter referred to as “the Extension”) is a browser extension tailored for corporate finance professionals. Its sole purpose is to provide auxiliary automation functions on official electronic tax‑bureau websites, reduce repetitive manual operations, and improve tax‑processing efficiency.

1. Data Access and Data Collection

The Extension does NOT collect, upload, receive, or persistently save any personal identifiable information, browsing history, or user‑identifiable data to any remote server.

To deliver core functions, the Extension may temporarily access the following data only locally within your browser when you visit official electronic tax‑bureau websites (*.chinatax.gov.cn):

  • Website cookies from electronic tax‑bureau domain for maintaining your logged‑in session;
  • Public webpage content displayed on electronic tax‑bureau pages, including tax‑related text and invoice information shown on‑screen.

No data described above is collected for analytics, advertising or any purpose unrelated to the extension’s core tax‑assisting function.

2. How We Use Accessed Data

  • Cookie data: Solely to preserve your login session status on the electronic tax‑bureau website so you can normally view and operate tax‑related web pages;
  • Web‑page content: Solely parsed locally inside your browser to implement auxiliary tax‑business processing features of this Extension.

All usage is restricted exclusively to realizing the extension’s declared functionality. No data is used for any other purpose.

3. Data Storage and Data Retention

All temporarily accessed webpage content is held only in browser volatile memory. This temporary in‑memory data is automatically cleared when you close the tab, exit the browser, or disable the Extension.

No user‑related data is stored on any external or cloud‑based server operated by us or third‑party service providers. The Extension does not use remote persistent storage. No copies of tax‑page content or cookie values are saved outside your local browser environment.

4. Data Sharing and Disclosure to Third Parties

The Extension does NOT share, sell, rent, or transfer any accessed data to any third‑party entities for any reason.

There is no transmission of user‑related information to advertisers, analytics vendors, cloud service providers, or any external third‑party organizations. No third‑party receives any data originating from your use of this Extension.

5. Permissions Explanation

  • cookies: Maintain logged‑in user session on electronic tax‑bureau websites to guarantee normal page access.
  • host permissions (https://*.chinatax.gov.cn/*): Allow access only to official electronic tax‑bureau web pages for parsing tax‑related content locally within the browser.

6. Remote Code Statement

All executable logic of this Extension is embedded inside the extension installation package. The Extension does not load, import or execute any external remote JavaScript or WebAssembly code from outside the extension bundle. No eval() or dynamic execution of network‑fetched text is used.

7. User Rights & Control

Because no personal user data is collected or stored on remote servers, there is no remote‑hosted personal data for users to access, modify or delete.

  • You may disable or uninstall this Extension at any time to stop all its functions immediately;
  • You can revoke browser permissions granted to this Extension through Chrome extension settings at any time.

8. Revision of This Privacy Policy

We may update this privacy policy occasionally. Updated versions will be published on this public page with a revised effective date.
